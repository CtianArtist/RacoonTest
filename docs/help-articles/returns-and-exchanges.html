What is your returns policy?

Category: Returns & refunds

Unused items can be returned within 30 days of delivery in the demo policy.

We accept returns of unused, unwashed items in their original condition within 30 days of delivery. For a support-flow test, ask through the Zendesk widget using sample order details.

Return steps

  1. Contact us for a fictional return authorization.
  2. Pack the item securely with your order reference.
  3. Send us the fictional tracking details when available.

Original shipping charges are not refundable. Personalized or clearly used items are not eligible. Exchanges are handled as a return plus a new demo order, because checkout is not enabled in this environment.

Demo notice: This is fictional policy content. No real returns or refunds can be processed.
