Can I cancel my order?

Category: Orders

Cancellation is possible only before the order enters packing.

Use the demo contact page as soon as possible and include your order number. We will check whether the order is still awaiting fulfillment.

If packing has started, cancellation may no longer be possible. You can instead ask about a return after delivery. No real orders or payments are created by this storefront.
