### Important security design

This environment is specifically intended to let me test security boundaries.

Structure the application so these concepts are very clear:

Authentication = Who is making the request?

Authorization = Is this user allowed to access this specific object?

Integration authentication = Is this request coming from the configured Zendesk integration?

The Zendesk integration must NOT automatically bypass customer-level authorization.

Keep those checks implemented in separate functions so they are easy to inspect and modify.
